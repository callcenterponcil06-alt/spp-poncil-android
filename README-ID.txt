Monitor Kamar — PROYEK ANDROID

Alamat awal: https://poncildarussalam.free.nf/monitor-kamar/?i=1
Package ID: com.poncildarussalam.monitor

CARA MEMBANGUN APK
1. Buka folder proyek ini menggunakan Android Studio (versi terbaru yang mendukung Android Gradle Plugin 8.7.3).
2. Tunggu Gradle Sync selesai dan pasang Android SDK Platform 35 jika diminta.
3. Pilih Build > Build Bundle(s) / APK(s) > Build APK(s).
4. APK debug akan berada di app/build/outputs/apk/debug/app-debug.apk.

Aplikasi ini adalah pembungkus WebView untuk website InfinityFree; data dan login tetap berada di server website. Koneksi internet diperlukan.
Catatan: upload berkas melalui formulir web perlu diuji di perangkat. Jika fitur pemilih berkas tidak berjalan pada halaman tertentu, implementasi FileChooser Android perlu disesuaikan. APK belum dikompilasi atau diuji pada perangkat dalam paket ini.
